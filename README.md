# E-Commerce Store

🛒 Overview

This is a front-end web project for an E-Commerce Store designed to provide an online shopping experience similar to Amazon. The platform offers a variety of branded products like Nike, Zara, and more, allowing users to browse, search, and purchase items seamlessly.

# Features
- Responsive Design – Optimized for all devices (mobile, tablet, and desktop).

- Product Listing – Displays various categories of products.

- Brand Filtering – Users can filter products based on brands like Nike, Zara, etc.

- Search Functionality – Allows users to find products quickly.

- Add to Cart – Users can select products and add them to their cart.

- Checkout Page – Provides a summary of selected items before purchasing.

- User Authentication (Future Enhancement) – Login/signup functionality for personalized shopping experience.

# Technologies Used

- HTML – Structure of the web pages.

- CSS – Styling and layout, ensuring a visually appealing interface.

- Flexbox – Used for creating flexible and responsive layouts.

- JavaScript (Future Enhancement) – To add interactive functionalities like cart management and checkout process.
